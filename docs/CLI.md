# Serielle CLI

Baudrate:

```text
115200
```

Prompt:

```text
fuell>
```

## Befehle

```text
help
?
wifi status
wifi scan
wifi ssid <SSID>
wifi pass <PASSWORT>
wifi save
wifi connect
wifi disconnect
wifi ap
wifi clear
mqtt status
mqtt test
mqtt reconnect
```

## Beispiel

```text
wifi ssid MeinWLAN
wifi pass MeinPasswort
wifi save
wifi connect
```

Das WLAN-Passwort wird bei Statusausgaben nicht im Klartext ausgegeben.
